Clenby — wordmark lockup

Two decisions, kept separate. Structure — how mark and word sit together — is what to pick now. Typeface comes after; these render in the system sans, and the shipped logo should be set in a chosen face and converted to outlines so it can’t reflow on someone else’s machine.

1 · Horizontal — the primary

Mark at 1.09× the cap height so it optically matches the lowercase; gap 0.42em; tracking −0.031em to close the wide default spacing. This is the one that goes in the site header and the store banner.

clenby

2 · Scaling — 44 / 24 / 17px

The whole lockup is em-based, so it scales as one object. Below ~15px the chevron closes up; that’s the floor for the horizontal lockup.

clenby clenby clenby

3 · Reversed

The mark keeps its indigo tile on dark — it does not go white. The tile is the constant; only the wordmark flips.

clenby clenby

4 · Stacked

For square slots — the store listing tile, an avatar, an OG image. Mark at 1.55em so the word doesn’t dominate.

clenby

5 · With tagline

Tagline at 0.30em of the lockup size, baseline-aligned under the wordmark. Use only at 32px and above.

6 · Typeface options — same structure, three voices

Semibold (default) reads as product. Light reads as editorial. Mono reads as developer tool — arguably the truest to what Clenby is, and it pairs with the terminal styling already in the gear menu.

7 · Clear space & minimum size

Keep a margin equal to twice the mark’s corner radius on all four sides. Minimum horizontal lockup: 17px tall. Below that use the mark alone.
